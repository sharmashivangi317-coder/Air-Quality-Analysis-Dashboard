# Air Quality Analysis and Prediction Dashboard

## 📌 Project Overview
This project focuses on analyzing and predicting air quality using historical pollution data. It combines **data analysis, data visualization, and machine learning** to provide both insights and future air quality predictions.

The project uses:
- **Power BI** for interactive dashboards
- **R Shiny (HTML)** for web-based visualization
- **Regression-based Machine Learning Model** to predict air quality levels

---

## 🎯 Objectives
- Analyze air quality trends over time
- Identify key pollutants affecting air quality
- Compare pollution levels across regions
- Predict air quality using a regression-based ML model
- Present insights through interactive dashboards

---

## 🧠 Machine Learning Model
- **Model Type:** Regression Model  
- **Purpose:** Predict air quality levels based on pollutant concentrations  
- **Input Features:** PM2.5, PM10, NO₂, SO₂, CO, O₃ (example – modify if needed)  
- **Target Variable:** Air Quality Index (AQI) / Pollution Level  
- **Approach:**
  - Data preprocessing and cleaning
  - Feature selection
  - Model training using regression technique
  - Model evaluation using performance metrics

### 📊 Model Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

## 🚀 How to Use the Project

### Power BI Dashboard
1. Download `AirQuality_Dashboard.pbix`
2. Open using **Power BI Desktop**
3. Explore interactive visuals and insights

### Shiny Dashboard
1. Open `rshiny.html` in a web browser
